Project Overview & Guidelines

About PixelCraft UI

PixelCraft UI is an open, educational web design system built specifically for an academic website design assignment. Its purpose is to demonstrate that modern, responsive, accessible web interfaces can be constructed using pure HTML5 and CSS3—completely free from JavaScript dependencies and heavy framework runtimes.

Transparent Academic Scope: This project is designed as an educational reference. It does not sell commercial subscriptions, does not collect personal data, and does not invent corporate history, fictitious awards, or fake testimonials.

1. Mission & Educational Purpose

In modern web engineering, beginners are frequently introduced to complex JavaScript frameworks (React, Vue, Angular) and utility frameworks before they fully grasp how semantic HTML and modern CSS work. This creates unnecessary cognitive overhead and hides the fundamental mechanics of the web platform.

PixelCraft UI exists to provide an authentic alternative: a comprehensive component library where every line of code is accessible, inspectable, and directly connected to W3C web standards. Students can study real Flexbox alignments, CSS Grid track definitions, media queries, and accessibility patterns without build tools getting in the way.

2. Target Audience

PixelCraft UI was designed from the ground up to support:

  • Web Design Students: Learners taking academic courses in frontend development who need clean, compliant HTML5/CSS3 references.
  • Beginner Frontend Developers: Programmers looking to solidify their CSS layout, typography, and responsive design fundamentals.
  • Freelance Web Designers: Practitioners seeking lightweight, zero-dependency starter patterns for fast-loading client sites.
  • UI/UX Learners: Designers transitioning into code who want to understand how design tokens and components map to native CSS.

3. Why Pure HTML & CSS?

Standard HTML and CSS offer distinct architectural advantages:

  • Zero Runtime Overhead: No JavaScript parsing, compilation, or hydration delays. Pages render instantly upon arrival.
  • Maximum Longevity: Native HTML and CSS written today will continue to render correctly in browsers for decades without package depreciation.
  • Accessible by Default: Leveraging native elements (<button>, <details>, <form>) provides built-in keyboard navigation and screen-reader semantics.
  • Portability: Components can be copied into any environment—static HTML sites, WordPress, Rails, Django, or React templates.

4. Core Project Principles

1. Standards First

We strictly write valid HTML5 elements and CSS3 custom properties according to W3C and WHATWG specifications.

2. Radical Honesty

We clearly disclose when a component is a visual UI demonstration (e.g. login forms) and require backend services for full operation.

3. Universal Accessibility

Every interactive control features a visible focus state, accessible contrast ratios exceeding 4.5:1, and reduced-motion handling.

4. Zero External Dependencies

No external npm dependencies, JavaScript UI toolkits, or CDN script trackers. Pure browser-native execution.

5. Honest Technical Limitations

As a pure frontend HTML/CSS project, PixelCraft UI embraces the following transparent constraints:

  • Static Form Demonstrations: Forms on this website do not store data, send emails, or authenticate accounts. Connecting them to a backend service (e.g. PHP, Node, or serverless functions) is required for real production submissions.
  • Manual Code Selection: Because JavaScript is strictly prohibited, there is no automatic clipboard-copy button. Users select and copy code blocks manually.
  • Category Navigation: In place of a simulated client-side search box, the library provides anchor-linked category navigation.
  • Native Browser Printing: Rather than claiming automatic server PDF generation, printing relies directly on standard browser printing (Ctrl+P / Cmd+P) supported by our print stylesheet.
Brand Kit Guidelines

PixelCraft UI Brand Kit & Identity Rules

The PixelCraft UI brand identity balances a contemporary developer-tool aesthetic with editorial clarity. Follow these guidelines when displaying the brand assets.

Logo Concept & Symbol Anatomy

The PixelCraft UI mark is a rounded square with an electric violet (#6C5CE7) container (~22% border radius). Inside, a 3×3 grid of small rounded pixels creates the pixel-art letter P using 7 crisp white pixels. The remaining pixel at the bottom-right is rendered in teal (#16B8A6), representing the creative "craft" accent.

Brand Rules

  • Clear Space: Always maintain a clear margin around the logo equal to at least twice the height of one pixel grid cell (approximately 16px).
  • Minimum Sizes: Minimum width for the horizontal wordmark is 120px; minimum width for the standalone symbol mark is 24px.
  • Approved Backgrounds: The logo may only be placed on approved canvas backgrounds: #F8F9FC, #FFFFFF, #151827, or #6C5CE7.
  • Prohibitions: Do not stretch, rotate, recolor, apply drop shadows, or place the logo over busy background imagery.
  • Iconography Style: All brand icons must be clean outline SVGs, rendered with a single 1.75px stroke width, rounded caps and joins, and colored using currentColor.

Typography Pairings

PixelCraft UI enforces a strict two-family typography system:

  • Headings & Display: Space Grotesk (weights 600, 700) with tight letter-spacing (-0.025em to -0.03em) for confident, editorial impact.
  • Body Text & UI Controls: Inter (weights 400, 500, 600) with a 1.65 line height for maximum readability on digital screens.
  • Code & Tokens: Monospace system font stack (ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, monospace).
