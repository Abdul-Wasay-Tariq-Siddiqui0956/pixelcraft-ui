Beginner Tutorial

Getting Started with PixelCraft UI

PixelCraft UI is a lightweight, zero-dependency HTML5 and CSS3 component library built for students and web design practitioners. Getting started requires nothing more than a text editor and a web browser—no Node.js build pipeline, no package installation, and no JavaScript runtime scripts.

Complete frontend implementation Beginner friendly
Prerequisites: Basic understanding of HTML elements (<header>, <nav>, <div>) and CSS classes. That's all! You can inspect, edit, and double-click your HTML files to preview changes locally in any modern browser.

Step 1: Set Up Your Project Folder Structure

Organize your project with a dedicated root folder containing your HTML files and an assets/ directory for stylesheets, images, and SVG icons. Here is the recommended folder structure:

Project Directory Tree Select and copy manually 
my-website/
├── index.html            <-- Your main website page
├── about.html            <-- Secondary content page
├── contact.html          <-- Contact & inquiry form
└── assets/
    ├── css/
    │   └── style.css     <-- PixelCraft UI master stylesheet
    ├── images/
    │   ├── logo.svg      <-- Brand logo asset
    │   └── favicon.svg   <-- Browser tab icon
    └── icons/
        ├── menu.svg      <-- Navigation drawer icon
        └── check.svg     <-- Feature checklist icon

Step 2: Create Your First HTML Document

Create an index.html file with the standard HTML5 doctype, viewport meta tag, and link to the PixelCraft UI stylesheet in the <head>:

HTML Boilerplate Select and copy manually 
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>My New Website | Built with PixelCraft UI</title>
    <meta name="description" content="Clean modern website built with pure HTML and CSS." />
    
    <!-- Connect PixelCraft UI Stylesheet (Supports both relative & absolute root) -->
    <link rel="stylesheet" href="assets/css/style.css" />
    <link rel="stylesheet" href="/assets/css/style.css" />
  </head>
  <body>
    <a href="#main" class="skip-link">Skip to main content</a>

    <main id="main" class="container">
      <h1>Welcome to My Website</h1>
      <p class="lead">This page is styled purely with standard CSS3.</p>
    </main>
  </body>
</html>

Step 3: Copy and Paste Component Examples

Navigate to any component page—such as Navbars, Forms, or Cards. Under the live preview, select the provided HTML snippet, paste it into your <body>, and refresh your browser. Because all classes are already included in style.css, your elements render immediately with full styling.

Step 4: Customize Colors & Design Tokens

Every visual design token is declared as a CSS variable at the top of assets/css/style.css inside the :root selector. You can change your brand palette in one place without touching individual components:

CSS Custom Properties assets/css/style.css 
:root {
  /* Primary Brand Accents */
  --primary: #6C5CE7;       /* Change to your brand color */
  --primary-600: #5848D3;   /* Hover/active state */
  --lavender: #A89BFA;      /* Secondary soft accent */
  --accent: #16B8A6;        /* Teal highlight */

  /* Backgrounds & Text */
  --bg: #F8F9FC;            /* Canvas background */
  --surface: #FFFFFF;       /* Card surface */
  --text: #171923;          /* High-contrast charcoal text */
  --text-muted: #626B7A;    /* Secondary body copy */

  /* Border Radii Tokens */
  --radius-1: 10px;
  --radius-2: 14px;
  --radius-3: 18px;
}

Step 5: Test Responsive Layouts

To inspect how your website behaves across screen sizes:

  • Open your index.html in Google Chrome, Firefox, or Safari.
  • Press F12 or Cmd+Option+I to open Developer Tools.
  • Click the Toggle Device Toolbar icon (Cmd+Shift+M or Ctrl+Shift+M).
  • Test standard breakpoints: 320px (small mobile), 375px (iPhone), 768px (tablet portrait), and 1024px+ (desktop).
  • Confirm there is no unintentional horizontal scrolling.

Step 6: Verify Keyboard Accessibility

A fundamental test of inclusive web design is navigating your site without a mouse:

  • Click your browser address bar and press Tab.
  • The Skip to main content link must appear at the top-left.
  • Continuing to press Tab will move sequentially through nav links, buttons, and form inputs.
  • Every focused element must display a visible 2px violet outline (--focus: #6C5CE7).
  • Pressing Enter or Space activates links and buttons natively.

Step 7: Test Browser Printing (@media print)

PixelCraft UI includes an accessible print stylesheet. Press Cmd+P or Ctrl+P to open your browser's Print Preview:

  • The sticky navigation header and footer are automatically hidden.
  • The background switches to pure white and typography converts to high-contrast black.
  • Code blocks remain intact with preserved formatting.
