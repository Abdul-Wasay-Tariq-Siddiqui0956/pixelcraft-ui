Design System Primitives

CSS Button Components & Interactive States

Buttons are the principal triggers for user action. The PixelCraft UI button system ensures strict semantic separation between action triggers (<button>) and navigation destinations (<a>), with comfortable ≥44px touch boundaries and visible keyboard focus rings.

When Should You Use a <button> vs an <a> Element?

Use an anchor tag (<a href="...">) whenever the control navigates to a new page, document, or section URL. Use a button tag (<button type="button|submit">) whenever the control triggers an in-page action, form submission, dialog toggle, or client state change without changing the URL.

Default, simulated hover, focus-visible outline, active pressed, and native disabled states.

HTML5 & CSS Source Select and copy manually (Ctrl+C / Cmd+C) 
<!-- Button Interactive State Rules -->
<button type="button" class="btn btn-primary">Normal</button>
<button type="button" class="btn btn-primary" disabled>Disabled</button>

<style>
/* Visible Focus Indicator (WCAG 2.4.7) */
.btn:focus-visible {
  outline: 2px solid #6c5ce7;
  outline-offset: 3px;
}

/* Hover Lift */
.btn:hover {
  transform: translateY(-1px);
}

/* Active Press */
.btn:active {
  transform: translateY(0);
}

/* Disabled State */
.btn:disabled,
.btn[aria-disabled="true"] {
  opacity: 0.55;
  cursor: not-allowed;
  pointer-events: none;
  transform: none;
}
</style>

Responsive Behavior

On touchscreens, :hover is not trapped thanks to :focus-visible separation, preventing sticky hover bugs on iOS and Android.

Accessibility Notes

The native disabled attribute automatically communicates non-interactivity to screen readers without requiring custom ARIA scripts.

4. Pure CSS Loading Spinner Demonstration

Visual loading state presentation using pure CSS keyframe rotation without client-side JavaScript.

CSS Keyframes No JavaScript
HTML5 & CSS Source Select and copy manually (Ctrl+C / Cmd+C) 
<!-- Pure CSS Loading Button (Visual Demonstration) -->
<button type="button" class="btn btn-primary" aria-busy="true">
  <span class="spinner spinner-white" aria-hidden="true"></span>
  <span>Processing Request...</span>
</button>

<style>
@keyframes spin {
  to { transform: rotate(360deg); }
}
.spinner {
  width: 16px;
  height: 16px;
  border: 2px solid rgba(108, 92, 231, 0.25);
  border-top-color: #6c5ce7;
  border-radius: 50%;
  animation: spin 0.8s linear infinite;
  display: inline-block;
}
.spinner-white {
  border-color: rgba(255, 255, 255, 0.3);
  border-top-color: #ffffff;
}
</style>

Responsive Behavior

Spinner diameter is calibrated to 16px to prevent button height distortion when swapping between normal and loading states.

Accessibility Notes

The aria-busy="true" attribute notifies screen readers of in-progress operations, and @media (prefers-reduced-motion) respects motion preferences.

Responsive Behavior

On mobile devices, .btn-lg provides ample surface for easy one-handed thumb interaction without accidental misses.

Accessibility Notes

Even the small button maintains a physical hit area meeting WCAG AA minimum standards (at least 24px inner + 8px outer touch envelope).
